# SCOPE Club — Official Website

The official static website for **SCOPE Club**, the student tech community at **MLRIT, Hyderabad**.

## About

SCOPE Club is built by builders, for builders. We exist to close the gap between classroom learning and real-world software development — through hands-on workshops, peer collaboration, and projects that actually ship.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home / landing page |
| `about.html` | Club mission and pillars |
| `what-we-do.html` | Activities and focus areas |
| `events.html` | Upcoming and past events |
| `resources.html` | Learning resources |
| `contact.html` | Contact and join form |

## Tech Stack

- Plain HTML5, CSS3, and vanilla JavaScript — no frameworks, no build step
- Google Fonts: Space Grotesk + Inter
- Fully responsive, mobile-first layout
- Dark theme with custom CSS variables

## Running Locally

No build step needed — just open any `.html` file in your browser, or serve with any static file server:

```bash
npx serve .
# or
python -m http.server
```
